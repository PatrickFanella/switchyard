## Open operational exceptions

- The remote deployment proof (`prove-production-deployment.yml`, run 9957)
  failed with an HTTP 404 from one endpoint configured in workflow secrets.
  This workflow has never passed in this repository; its only earlier run
  (v0.2.3, run 5450) failed at the checkout-identity step. Manual probes from
  Almaz on 2026-09-25 returned the contract responses: web root and `/healthz`
  200, control `/api/operator-safety` and `/api/operator-summary` through the
  web proxy with the read token 200, model `/health`, `/broker/status`, and
  `/api/tags` 200, and model `/api/runs` 404. The workflow secrets need review
  before the remote proof can be claimed.
- The prepared Open Pilot verifier images were not rebuilt. They remain bound
  to earlier source revisions, so Open Pilot verification of this repository
  requires re-preparation before admission is re-enabled.
- No application rollback rehearsal was performed for this release.
