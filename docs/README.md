# Documentation

This directory is the current project knowledge base.

Historical OCQ, llama-line, and Changemaker references are kept here as ADRs and migration notes; their imported directories were removed when the native Switchyard modules landed.

## Sections

- `status.md` — current capability state, evidence level, and release blockers
- `releases/` — qualification records tied to exact revisions
- `adr/` — architecture decision records
- `reference/` — stable technical references
- `research/` — exploratory notes, comparisons, and findings
- `runbooks/` — repeatable operational procedures
- `labels.md` — Open Pilot label lifecycle
- `open-pilot.md` — how to prepare issues for Open Pilot

Dated plans under `superpowers/plans/` are historical implementation records, not live status trackers.

Keep docs current, concise, and linked from this hub.
